# PaceNotes

Retro pixel rally. Pace-note call-outs, gravel, snow and tarmac, jumps, cliffs and checkpoints against the clock.

Live: https://lhcars.my/PaceNotes/

Root = built game (Vite, base /PaceNotes/). Source in `source/` (`src/engine.ts` is the shared LH Cars Arcade engine, `src/main.ts` is the game).
